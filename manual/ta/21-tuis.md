# TUIs

## Lazygit

[Lazygit](https://github.com/jesseduffield/lazygit) என்பது GitHub Desktop போன்ற ஒரு செயலிக்கு மகிழ்ச்சி தரும் மாற்றாகும், மேலும் இது டெர்மினலுக்குள் இயங்குகிறது.

git மூலம் நிர்வகிக்கப்படும் எந்தக் கோப்பகத்திற்கும் சென்று `lazygit` என்று இயக்குவதன் மூலம் இதை நேரடியாக இயக்கலாம். அல்லது Neovim-க்குள் இதை இயக்கலாம், அங்கு இதை `Space G G` மூலம் தொடங்கலாம்.

`Tab` ஐப் பயன்படுத்தி வெவ்வேறு பலகங்களுக்கு இடையே தாவுகிறீர்கள். Files பலகத்தில், `Space` ஐப் பயன்படுத்தி நிலைப்படுத்துவதற்கான கோப்புகளைத் தேர்ந்தெடுக்கிறீர்கள், பின்னர் `c` ஐப் பயன்படுத்தி ஒரு புதிய commit ஐ உருவாக்கலாம். `?` ஐப் பயன்படுத்தி கிடைக்கும் அனைத்து கட்டளைகளையும் காணலாம்.

## Btop

[Btop](https://github.com/aristocratos/btop) என்பது நினைவகம், CPU, வட்டு மற்றும் வலையமைப்புப் பயன்பாட்டைக் காட்டும் ஒரு அழகான வள மேலாளர். இது செயலில் உள்ள அனைத்து செயல்முறைகளையும் பட்டியலிடுகிறது, அவற்றை நிர்வகிக்கவும் உங்களை அனுமதிக்கிறது.

Omarchy இதை Activity Monitor என்று அழைக்கிறது, நீங்கள் இதைச் செயலி துவக்கியிலிருந்து அல்லது `Super + Shift + T` ஐ அழுத்துவதன் மூலம் தொடங்குகிறீர்கள். இது ஒரு மிதக்கும் சாளரமாகத் திறக்கும், இதை `Super + T` மூலம் அடுக்கலாம்.

## Herdr

[Herdr](https://github.com/omacom-io/herdr) என்பது உங்களுக்குப் பணியிடங்கள், தாவல்கள் மற்றும் பலகங்களை வழங்கும் ஒரு டெர்மினல் பணியிட மேலாளர், மேலும் அவை அனைத்தையும் நீங்கள் பிரிந்து பின்னர் மீண்டும் வரக்கூடிய ஒரு நிலையான அமர்வில் தொடர்ந்து இயங்க வைக்கிறது.

செயலி துவக்கியிலிருந்து அல்லது `Super + Ctrl + Return` மூலம் இதைத் தொடங்குகிறீர்கள் (அல்லது உங்கள் தற்போதைய அமர்வுடன் மீண்டும் இணைகிறீர்கள்). Omarchy அதன் Tmux கட்டமைப்பைப் பிரதிபலிக்கும் ஒரு Herdr கட்டமைப்பை வழங்குகிறது, எனவே இங்கும் முன்னொட்டு விசை `Ctrl + Space` தான். `Super + Ctrl + K` மூலம் அனைத்து விசைப்பிணைப்புகளையும் உலாவலாம்.

## Fastfetch

[Fastfetch](https://github.com/fastfetch-cli/fastfetch) கர்னல் பதிப்பு, இயக்க நேரம், தீம், CPU, நினைவகம் மற்றும் இன்னும் பல போன்ற கணினித் தகவல்களைக் காட்டுகிறது. இது பிரபலமான neofetch கருவியின் வாரிசு.

Omarchy இதை Omarchy மெனுவில் (`Super + Space`) _About_ என்று தொகுத்துள்ளது.

## Cliamp

[Cliamp](https://www.cliamp.stream/) என்பது Winamp 2.x ஆல் ஈர்க்கப்பட்ட ஒரு ரெட்ரோ டெர்மினல் இசை இயக்கி, lo-fi beats-க்கான உள்ளமைக்கப்பட்ட வானொலி நிலையங்களுடன் முழுமையானது. `Super + Shift + Alt + M` மூலம், அல்லது Omarchy மெனுவில் _Apps_ இன் கீழ் இதைத் துவக்கவும். முழு விசைப்பிணைப்புப் பட்டியலுக்கு `?` ஐ அழுத்தவும்.

## Wi-Fi மற்றும் Bluetooth பற்றி என்ன?

Wi-Fi மற்றும் Bluetooth-க்கு TUIs கிடைக்காது — அந்த வேலைகள் Omarchy shell-க்கு உரியவை. வலையமைப்புகளைக் கண்டு இணைக்க மேல் பட்டியில் உள்ள Wi-Fi சின்னத்தைக் கிளிக் செய்யவும் (அல்லது `Super + Ctrl + N` ஐ அழுத்தவும்), சாதனங்களை இணைத்து இணைக்க Bluetooth சின்னத்தைக் கிளிக் செய்யவும் (அல்லது `Super + Ctrl + B` ஐ அழுத்தவும்). முழுக் கதைக்கும் [வலையமைப்பு](35-networking.md) ஐப் பார்க்கவும்.

## உங்களுடையதைச் சேர்ப்பது

எந்த டெர்மினல் நிரலும் முழு செயலி அந்தஸ்தைப் பெறலாம். Omarchy மெனுவில் (`Super + Space`) _Install > TUI_ க்குச் சென்று, அதற்கு ஒரு பெயர், ஒரு துவக்க கட்டளை, ஒரு சாளர பாணி மற்றும் ஒரு சின்னத்தைக் கொடுங்கள், அது மற்ற எந்தச் செயலியையும் போலச் செயலி துவக்கியில் தோன்றும். _Remove > TUI_ இன் கீழ் அதை மீண்டும் அகற்றலாம்.
