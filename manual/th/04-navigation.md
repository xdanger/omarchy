# การนำทาง

ทุกอย่างใน Omarchy เกิดขึ้นผ่านคีย์บอร์ด — _ทุกอย่าง!_ เมื่อระบบเริ่มทำงานครั้งแรก คุณใช้เมาส์อย่างเดียวทำอะไรไม่ได้เลยจริง ๆ แต่คุณกด `Super + Space` เพื่อเปิด Omarchy Menu ได้ และจากตรงนี้คุณทำได้แทบทุกอย่าง

แต่ Omarchy Menu ไม่ได้ถูกตั้งใจให้เป็นวิธีหลักในการใช้งานระบบตลอดเวลาด้วยซ้ำ เราเร็วกว่านั้นได้! แอปพลิเคชันสำคัญที่สุดทั้งหมดถูกผูกไว้กับปุ่มลัดโดยตรง คุณเปิดเทอร์มินัลด้วย `Super + Return` และเปิดเบราว์เซอร์ด้วย `Super + Shift + Return` ลองทำอันหนึ่งแล้วตามด้วยอีกอัน แล้วคุณจะเห็นความมหัศจรรย์ของการจัดเรียงแบบ tiling ของ Hyprland ทำงาน:

 ![navigation-browser-terminal](images/navigation-browser-terminal.webp)

จากนั้นคุณกด `Super + J` เพื่อซ้อนพวกมันไว้บนกันแทนที่จะวางข้างกัน:

 ![navigation-stacked](images/navigation-stacked.webp)

กด `Super + J` อีกครั้งเพื่อคืนพวกมันกลับไปยังตำแหน่งข้างกัน จากนั้นลอง `Super + Shift + Arrow Right` ขณะอยู่ในเบราว์เซอร์เพื่อสลับหน้าต่าง

ตอนนี้ลอง `Super + Shift + T` เพื่อเปิด Activity monitor หน้าต่างนั้นจะปรากฏเป็นหน้าต่างลอย คุณสามารถทำให้มันเป็นแบบ tiling ได้ด้วย `Super + T` (และกดอีกครั้งเพื่อทำให้มันลอยอีกครั้ง) ตอนนี้กด `Super + Shift + F` เพื่อเปิดตัวจัดการไฟล์ คุณจะได้การจัดวางสี่ช่องอย่างเรียบร้อย:

 ![navigation-fourway-tiling](images/navigation-fourway-tiling.webp)

คุณนำทางระหว่างหน้าต่างที่คุณต้องการให้เป็นหน้าต่างที่ใช้งานอยู่ด้วย `Super + Arrow` การทำเช่นนี้จะสลับโฟกัสและย้ายเคอร์เซอร์ไปตรงกลางของแอปพลิเคชันใหม่ ที่ขอบของหน้าจอ มันจะต่อเนื่องไปยังมอนิเตอร์ในด้านนั้น

ถ้าคุณกด `Super + Shift + 2` คุณจะย้ายแอปพลิเคชันที่กำลังโฟกัสอยู่ในปัจจุบันไปยังเวิร์กสเปซที่สอง `Super + Shift + 1` จะย้ายมันกลับ (และ `Super + Shift + Alt + 2` จะย้ายแอปพลิเคชันที่กำลังโฟกัสอยู่ในปัจจุบันไปยังเวิร์กสเปซที่สองโดยไม่สลับไปยังเวิร์กสเปซนั้น)

เมื่อมีมากกว่าหนึ่งมอนิเตอร์ ทุกมอนิเตอร์จะมีเวิร์กสเปซ 1 ถึง 10 ของตัวเอง `Super + 2` ไปยังเวิร์กสเปซที่สองของมอนิเตอร์ที่คุณอยู่ และแถบด้านบนของแต่ละมอนิเตอร์จะแสดงเวิร์กสเปซของตัวเองและเวิร์กสเปซที่กำลังแสดง `Super + Tab` จะวนผ่านเวิร์กสเปซบนมอนิเตอร์ที่คุณอยู่ `Super + Shift + Ctrl + Arrows` จะย้ายหน้าต่างที่คุณอยู่ไปยังมอนิเตอร์ในทิศทางนั้น ไปยังเวิร์กสเปซที่มอนิเตอร์นั้นกำลังแสดง และ `Super + Shift + Alt + Arrows` จะย้ายเวิร์กสเปซที่คุณอยู่ไปยังมอนิเตอร์ในทิศทางนั้น ซึ่งมันจะใช้หมายเลขเดียวกันถ้าว่าง มอนิเตอร์จะเก็บเวิร์กสเปซของมันไว้เมื่อคุณถอดปลั๊ก: พวกมันจะเข้าร่วมกับหน้าจออื่น โดยมีหมายเลขต่อจากที่มีอยู่แล้ว และกลับไปอยู่ภายใต้หมายเลขเดิมเมื่อมอนิเตอร์กลับมา

ถ้าคุณกด `Super` ค้างไว้และใช้เมาส์คลิกบนหน้าต่าง คุณจะสามารถจัดเรียงตำแหน่งที่มันอยู่ได้ ถ้าคุณกด `Super` ค้างไว้และใช้ปุ่มขวาของเมาส์ คุณสามารถปรับขนาดหน้าต่างได้อย่างอิสระ

คุณปิดหน้าต่างด้วย `Super + W` หรือ `Super + Q` (และปิดหน้าต่างทั้งหมดด้วย `Ctrl + Alt + Delete`)

คุณยังสามารถแสดงเต็มหน้าจอด้วย `Super + F` หรือแม้แต่แค่เต็มความกว้าง (โดยยังคงแถบด้านบนไว้) ด้วย `Super + Alt + F` หรือเต็มหน้าจอภายในหน้าต่างด้วย `Super + Ctrl + F` (เหมาะสำหรับ YouTube!)

### เลย์เอาต์ dwindle เทียบกับ scrolling

เลย์เอาต์เริ่มต้นของ Omarchy เรียกว่า dwindle มันทำให้หน้าต่างทั้งหมดที่คุณเปิดบนเวิร์กสเปซเดียวมองเห็นได้ตลอดเวลา แม้ว่าจะต้องย่อพวกมันลงก็ตาม

 ![navigation-dwindle-layout](images/navigation-dwindle-layout.webp)

แต่คุณยังสามารถเลือกเปลี่ยนเวิร์กสเปซให้เป็นเลย์เอาต์ scrolling ที่หน้าต่างถูกเรียงข้างกัน เกินขอบที่มองเห็นได้ของหน้าจอ คุณเปลี่ยนเวิร์กสเปซเดียวให้เป็นเลย์เอาต์นี้ได้ผ่าน `Super + L`

การกด `Super + L` อีกครั้งจะเปลี่ยนเวิร์กสเปซเป็นแบบลอย ที่หน้าต่างทับซ้อนกันอย่างอิสระและคุณวางพวกมันเอง และการกดครั้งที่สามจะคืนกลับเป็น dwindle `Super + Alt + L` จะวนผ่านพวกมันไปในทิศทางอื่น หน้าต่างที่ลอยอยู่แล้ว — หน้าต่างที่คุณดึงออกมาด้วย `Super + T` หรือแอปที่เปิดแบบลอยเสมอ — จะยังคงลอยอยู่เมื่อเวิร์กสเปซกลับไปเป็นแบบ tiling แถบด้านบนจะทำเครื่องหมายเวิร์กสเปซที่คุณอยู่ด้วยเลย์เอาต์ของมัน: สี่เหลี่ยมจัตุรัสสำหรับ dwindle วงกลมสำหรับ scrolling และสามเหลี่ยมสำหรับแบบลอย การคลิกเครื่องหมายนั้นก็จะวนเปลี่ยนเลย์เอาต์เช่นกัน

 ![navigation-scrolling-layout](images/navigation-scrolling-layout.webp)

การเลือกเป็นแบบต่อเวิร์กสเปซ และมันจะคงอยู่ ดังนั้นคุณสามารถให้เวิร์กสเปซ 1 เป็น dwindle สำหรับการท่องเว็บและเวิร์กสเปซ 2 เป็น scrolling สำหรับโค้ด และพวกมันจะกลับมาเป็นแบบนั้นหลังจากรีสตาร์ท

ถ้าคุณต้องการใช้เลย์เอาต์ scrolling เป็นค่าเริ่มต้น คุณสามารถตั้งค่าได้ใน `~/.config/hypr/looknfeel.lua`:

```lua
hl.config({
  general = {
    layout = "scrolling",
  },
})
```

### เวิร์กสเปซแบบลอย

เวิร์กสเปซแบบลอยทำงานเหมือนเดสก์ท็อปแบบดั้งเดิม: หน้าต่างทับซ้อนกัน และคุณย้ายและปรับขนาดพวกมันเอง แต่ละหน้าต่างจะได้รับแถบชื่อเรื่องในสีของธีมของคุณ พร้อมปุ่มเพื่อย่อ ขยาย และปิด `Super + M` จะย่อหน้าต่างที่กำลังโฟกัสอยู่ด้วย หน้าต่างที่ย่อแล้วจะรออยู่ใน dock; คลิกแอปของมันเพื่อนำมันกลับมา คลิกหน้าต่างเพื่อนำมันมาข้างหน้า ปรับขนาดมันจากขอบหรือมุมใดก็ได้ ดับเบิลคลิกแถบชื่อเรื่องเพื่อขยายหน้าต่างขณะที่ยังคงแถบด้านบนให้เห็น และอีกครั้งเพื่อคืนขนาดเดิมของมัน Chrome และเบราว์เซอร์ที่ใช้ Chromium เป็นฐานอื่น ๆ Disks และ Document Viewer จะข้ามแถบชื่อเรื่องและใช้ส่วนหัวของตัวเองแทน; `Super + Alt + F` จะขยายพวกมัน และ `Super + M` จะย่อพวกมัน

เวิร์กสเปซแบบลอยยังแสดง dock พร้อมแอปที่ปักหมุดของคุณ ทุกอย่างที่กำลังทำงานอยู่ และตารางของทุกแอปหลังปุ่มแอป ซึ่ง `Super + Alt + Space` และ _Apps_ ใน Omarchy Menu ก็เปิดเช่นกัน คลิกขวาที่แอปบนตาราง หรือกด `Delete` เพื่อถอนการติดตั้งมัน คลิกแอปเพื่อเปิดมัน หรือเพื่อนำหน้าต่างของมันมาข้างหน้า; คลิกอีกครั้งเพื่อวนผ่านหน้าต่างของมัน Files จะนำหน้าต่างกลับมาเฉพาะจากเวิร์กสเปซที่คุณอยู่ และไม่เช่นนั้นจะเปิดหน้าต่างใหม่ และ Terminal และ Agent จะเริ่มอีกอันเสมอ แม้ว่าหน้าต่างที่ย่อแล้วจะกลับมาก่อน คลิกกลางจะเปิดหน้าต่างใหม่ ลากไอคอนไปตาม dock เพื่อย้ายมัน; การลากแอปที่กำลังทำงานอยู่เข้าไปในหมู่แอปอื่น ๆ จะเก็บมันไว้ตรงนั้น คลิกขวาเพื่อเก็บแอปไว้ใน dock นำมันออก หรือออกมัน dock จะหลีกทางให้กับหน้าต่างเต็มหน้าจอ คลิกขวาที่ปุ่มแอปเพื่อย้าย dock ไปยังอีกขอบหนึ่งหรือให้มันซ่อนจนกว่าตัวชี้จะไปถึงขอบของมัน ตำแหน่งยังอยู่ภายใต้ _Appearance > Dock > Dock Position_ และ `omarchy dock position left` และ `omarchy dock autohide on` จะตั้งค่าทั้งสองจากเทอร์มินัล แอปที่คุณเก็บไว้ใน dock จะจางลงขณะที่พวกมันไม่ได้ทำงานอยู่

เวิร์กสเปซใหม่ และเวิร์กสเปซใด ๆ ที่คุณยังไม่ได้กำหนดเลย์เอาต์ของตัวเองด้วย `Super + L` จะใช้เลย์เอาต์เริ่มต้น การเปลี่ยนค่าเริ่มต้นจะรีเซ็ตทุกเวิร์กสเปซที่ไม่มีหน้าต่างให้เป็นแบบนั้น ในขณะที่เวิร์กสเปซที่มีหน้าต่างอยู่จะเก็บเลย์เอาต์ที่มีอยู่ หน้าต่างที่ย่อไปยัง dock ยังนับเป็นหน้าต่างบนเวิร์กสเปซที่มันจากมา เลือกมันภายใต้ _Appearance > Workspace Layout_: Tiling, Scrolling, หรือ Floating `omarchy-hyprland-workspace-layout-default scrolling` จะตั้งค่ามันจากเทอร์มินัล

### การจัดกลุ่มหน้าต่าง

หน้าต่างสามารถจัดกลุ่มได้โดยใช้ `Super + G` เมื่อคุณอยู่ในกลุ่มแล้ว ทุกหน้าต่างที่คุณเริ่มขณะที่กลุ่มนั้นใช้งานอยู่จะเป็นของกลุ่มนั้น คุณสามารถย้ายระหว่างหน้าต่างที่จัดกลุ่มเหล่านี้โดยใช้ `Super + Ctrl + Arrow Left/Right` หรือ `Super + Alt + 1/2/3/4` เพื่อไปยังหน้าต่างที่จัดกลุ่มตามลำดับโดยตรง

คุณสามารถย้ายหน้าต่างออกจากกลุ่มด้วย `Super + Alt + G` หรือแยกกลุ่มทั้งหมดโดยกด `Super + G` อีกครั้ง สุดท้าย คุณสามารถย้ายหน้าต่างที่อยู่นอกกลุ่มเข้าไปในกลุ่มด้วย `Super + Alt + Arrows`

### การดึงหน้าต่างออก

คุณสามารถดึงหน้าต่างออกจากการจัดสรรเวิร์กสเปซของมันด้วย `Super + O` การทำเช่นนี้จะปักหมุดมันเป็นหน้าต่างลอยที่ตามคุณไปไม่ว่าคุณจะไปยังเวิร์กสเปซใด เหมาะมากสำหรับเครื่องเล่นวิดีโอและสิ่งที่คล้ายกัน

 ![navigation-popped-window](images/navigation-popped-window.webp)

### เวิร์กสเปซ scratchpad

มีเวิร์กสเปซ scratchpad พิเศษแบบเต็มขนาดที่วางทับเวิร์กสเปซใดก็ตามที่คุณอยู่ ณ ขณะนั้น คุณเข้าถึงสิ่งที่อยู่บนมันโดยใช้ `Super + S` และคุณวางหน้าต่างไว้ที่นั่นโดยใช้ `Super + Alt + S`

มันเหมาะสำหรับส่วนควบคุมหรือเทอร์มินัลที่คุณต้องการโต้ตอบด้วยอย่างรวดเร็วโดยไม่ต้องออกจากเวิร์กสเปซปัจจุบัน

### คอนโซล Quake

สุดท้าย มีคอนโซล Quake แบบครึ่งความสูงที่เลื่อนลงมาทับเวิร์กสเปซใดก็ตามที่คุณอยู่ ณ ขณะนั้น สลับมันด้วย `Super + Grave` และวางหน้าต่างไว้ที่นั่นโดยใช้ `Super + Shift + Grave`

มันเปิดพร้อมกับ agent เริ่มต้นของคุณพร้อมใช้งาน ขณะที่คอนโซลมีหน้าต่างเดียว มันจะเลื่อนลงมาเป็นแผงที่อยู่ตรงกลางแทนที่จะทอดเต็มหน้าจอ วางแอปที่สองลงบนมันและมันจะกลับไปเป็นความกว้างเต็ม เพื่อให้ทั้งสองมีพื้นที่วางข้างกัน

เพื่อย้ายหน้าต่างออกจาก scratchpad หรือคอนโซล ให้ส่งมันไปยังเวิร์กสเปซอื่นโดยตรงด้วยบางอย่างเช่น `Super + Shift + 1`

### ต้องใช้เวลาทำความคุ้นเคยสักหน่อย!

ต้องใช้เวลาสักพักเพื่อทำความคุ้นเคยกับการนำทางเดสก์ท็อปของคุณแบบนี้ แต่เมื่อคุณคุ้นเคยแล้ว มันจะยากที่จะกลับไปสู่ประสบการณ์เดสก์ท็อปแบบดั้งเดิมที่ขับเคลื่อนด้วยเมาส์!
