# ניווט

הכול ב-Omarchy קורה דרך המקלדת — _הכול!_ כשהמערכת עולה לראשונה, ממש אי אפשר לעשות שום דבר עם העכבר לבדו. אבל אפשר ללחוץ על `Super + Space` כדי לחשוף את תפריט Omarchy ומכאן אפשר לעשות כמעט הכול.

אבל תפריט Omarchy אפילו לא נועד להיות הדרך העיקרית להפעיל את המערכת רוב הזמן. אפשר להיות מהירים יותר מזה! כל היישומים החשובים ביותר קשורים ישירות למקשי קיצור נפרדים. מפעילים את המסוף עם `Super + Return` ודפדפן עם `Super + Shift + Return`. נסו לעשות אחד אחרי השני, ותראו את הקסם של הריצוף של Hyprland בפעולה:

 ![navigation-browser-terminal](images/navigation-browser-terminal.webp)

אחר כך אפשר ללחוץ על `Super + J` כדי לערום אותם זה על גבי זה במקום זה לצד זה:

 ![navigation-stacked](images/navigation-stacked.webp)

לחצו שוב על `Super + J` כדי להחזיר אותם למיקומים זה לצד זה. אחר כך נסו את `Super + Shift + Arrow Right` בזמן שאתם בדפדפן כדי להחליף בין החלונות.

עכשיו נסו את `Super + Shift + T` כדי להפעיל את Activity monitor. הוא יופיע כחלון צף. אפשר לרצף אותו באמצעות `Super + T` (וללחוץ על זה שוב כדי להפוך אותו שוב לצף). עכשיו לחצו על `Super + Shift + F` כדי לפתוח את מנהל הקבצים. תהיה לכם פריסה מסודרת של ארבעה:

 ![navigation-fourway-tiling](images/navigation-fourway-tiling.webp)

מנווטים בין החלונות כדי שהחלון הרצוי יהיה הפעיל באמצעות `Super + Arrow`. זה יחליף את המוקד ויעביר את הסמן למרכז היישום החדש. בקצה של מסך, זה ממשיך אל הצג שבאותו צד.

אם תלחצו על `Super + Shift + 2`, תעבירו את היישום הנמצא כרגע במוקד אל מרחב העבודה השני. `Super + Shift + 1` מחזיר אותו. (ו-`Super + Shift + Alt + 2` יעביר את היישום הנמצא כרגע במוקד אל מרחב העבודה השני בלי לעבור אליו).

כשיש יותר מצג אחד, לכל צג יש מרחבי עבודה 1 עד 10 משלו. `Super + 2` עובר אל מרחב העבודה השני של הצג שאתם נמצאים עליו, והסרגל העליון של כל צג מציג את מרחבי העבודה שלו ואת זה שהוא מציג. `Super + Tab` עובר במחזוריות בין מרחבי העבודה בצג שאתם נמצאים עליו. `Super + Shift + Ctrl + Arrows` מעביר את החלון שאתם נמצאים עליו אל הצג שבאותו כיוון, אל מרחב העבודה שהוא מציג, ו-`Super + Shift + Alt + Arrows` מעביר את מרחב העבודה שאתם נמצאים עליו אל הצג שבאותו כיוון, שם הוא מקבל את אותו מספר אם הוא פנוי. צג שומר את מרחבי העבודה שלו כשמנתקים אותו: הם מצטרפים לאלה של מסך אחר, במספור אחרי אלה שכבר יש לו, וחוזרים למספרים הישנים שלהם כשהצג חוזר.

אם תחזיקו את `Super` ותשתמשו בעכבר כדי ללחוץ על חלון, תוכלו לסדר מחדש היכן הוא יושב. אם תחזיקו את `Super` ותשתמשו בכפתור הימני של העכבר, תוכלו לשנות את גודל החלון בחופשיות.

סוגרים חלון עם `Super + W` או `Super + Q` (וסוגרים את כל החלונות עם `Ctrl + Alt + Delete`).

אפשר גם לעבור למסך מלא עם `Super + F` או אפילו רק לרוחב מלא (תוך שמירה על הסרגל העליון) עם `Super + Alt + F` או למסך מלא בתוך חלון עם `Super + Ctrl + F` (טוב בשביל YouTube!).

### פריסת dwindle מול פריסת scrolling

פריסת ברירת המחדל של Omarchy נקראת dwindle. היא שומרת את כל החלונות שאתם פותחים במרחב עבודה אחד גלויים בכל עת, גם אם היא צריכה לכווץ אותם.

 ![navigation-dwindle-layout](images/navigation-dwindle-layout.webp)

אבל אפשר גם לבחור להפוך מרחב עבודה לפריסת scrolling שבה החלונות מסודרים זה לצד זה, מעבר לקצה הגלוי של התצוגה. הופכים מרחב עבודה אחד לפריסה הזו באמצעות `Super + L`.

לחיצה נוספת על `Super + L` הופכת את מרחב העבודה לצף, שבו החלונות חופפים בחופשיות ואתם ממקמים אותם בעצמכם, ולחיצה שלישית מחזירה אותו ל-dwindle. `Super + Alt + L` עובר ביניהן בכיוון ההפוך. חלון שצף בכל מקרה — אחד שהוצאתם החוצה עם `Super + T`, או יישום שתמיד נפתח כצף — נשאר צף כשמרחב העבודה חוזר לריצוף. הסרגל העליון מסמן את מרחב העבודה שאתם נמצאים עליו בפריסה שלו: ריבוע בשביל dwindle, עיגול בשביל scrolling, ומשולש בשביל צף. גם לחיצה על הסימון הזה מעבירה את הפריסה במחזוריות.

 ![navigation-scrolling-layout](images/navigation-scrolling-layout.webp)

הבחירה היא לפי מרחב עבודה, והיא נשארת. כך אפשר להשאיר את מרחב עבודה 1 על dwindle בשביל גלישה ואת מרחב עבודה 2 על scrolling בשביל קוד, והם יחזרו כך אחרי הפעלה מחדש.

אם תרצו להשתמש בפריסת scrolling כברירת המחדל, אפשר להגדיר זאת ב-`~/.config/hypr/looknfeel.lua`:

```lua
hl.config({
  general = {
    layout = "scrolling",
  },
})
```

### מרחבי עבודה צפים

מרחב עבודה צף עובד כמו שולחן עבודה מסורתי: החלונות חופפים, ואתם מזיזים ומגדירים את גודלם בעצמכם. כל חלון מקבל שורת כותרת בצבעי ערכת הנושא שלכם, עם כפתורים למזער, להגדיל ולסגור. גם `Super + M` ממזער את החלון שבמוקד. חלון ממוזער מחכה ב-dock; לחצו על היישום שלו כדי להחזיר אותו. לחצו על חלון כדי להביא אותו קדימה. שנו את גודלו מכל קצה או פינה. לחצו לחיצה כפולה על שורת כותרת כדי להגדיל את החלון תוך שמירה על הסרגל העליון גלוי, ושוב כדי להחזיר את גודלו הישן. Chrome ודפדפנים אחרים מבוססי Chromium, Disks ו-Document Viewer מדלגים על שורת הכותרת ומשתמשים בכותרת משלהם במקום זאת; `Super + Alt + F` מגדיל אותם, ו-`Super + M` ממזער אותם.

מרחב עבודה צף מציג גם dock, עם היישומים המוצמדים שלכם, כל מה שרץ, ורשת של כל יישום מאחורי כפתור היישומים, שגם `Super + Alt + Space` ו-_Apps_ בתפריט Omarchy פותחים. לחצו לחיצה ימנית על יישום ברשת, או לחצו על `Delete`, כדי להסיר את התקנתו. לחצו על יישום כדי לפתוח אותו, או כדי להביא את החלון שלו קדימה; לחצו שוב כדי לעבור במחזוריות בין החלונות שלו. Files רק מחזיר חלון ממרחב העבודה שאתם נמצאים עליו ואחרת פותח חדש, ו-Terminal ו-Agent תמיד מפעילים עוד אחד, אם כי חלון ממוזער חוזר קודם. לחיצה אמצעית פותחת חלון חדש. גררו סמל לאורך ה-dock כדי להזיז אותו; גרירת יישום רץ פנימה בין האחרים משאירה אותו שם. לחצו לחיצה ימנית כדי להשאיר יישום ב-dock, להוציא אותו, או לצאת ממנו. ה-dock מפנה את הדרך לחלון במסך מלא. לחצו לחיצה ימנית על כפתור היישומים כדי להעביר את ה-dock לקצה אחר או לגרום לו להסתתר עד שהמצביע מגיע לקצה שלו. המיקום נמצא גם תחת _Appearance > Dock > Dock Position_, ו-`omarchy dock position left` ו-`omarchy dock autohide on` מגדירים את שניהם ממסוף. יישומים שאתם משאירים ב-dock דהויים בזמן שהם לא רצים.

מרחבי עבודה חדשים, וכל אלה שלא נתתם להם פריסה משלהם עם `Super + L`, משתמשים בפריסת ברירת המחדל. שינוי ברירת המחדל מאפס אליה כל מרחב עבודה בלי חלונות, בעוד שאחד שיש עליו חלונות שומר את הפריסה שיש לו. חלון שממוזער ל-dock עדיין נחשב כחלון במרחב העבודה שהוא עזב. בחרו אותה תחת _Appearance > Workspace Layout_: Tiling, Scrolling, או Floating. `omarchy-hyprland-workspace-layout-default scrolling` מגדיר אותה ממסוף.

### קיבוץ חלונות

אפשר לקבץ חלונות באמצעות `Super + G`. ברגע שאתם בקבוצה, כל חלון שתפעילו בזמן שהיא פעילה ישתייך לקבוצה. אפשר לנוע בין החלונות המקובצים האלה באמצעות `Super + Ctrl + Arrow Left/Right` או `Super + Alt + 1/2/3/4` כדי לעבור ישירות לחלונות מקובצים לפי הסדר.

אפשר להוציא חלון מהקיבוץ עם `Super + Alt + G` או לפרק את הקבוצה כולה על ידי לחיצה שוב על `Super + G`. לבסוף, אפשר להעביר חלונות שמחוץ לקבוצה לתוכה עם `Super + Alt + Arrows`.

### הוצאת חלונות החוצה

אפשר להוציא חלון החוצה מהקצאת מרחב העבודה שלו עם `Super + O`. זה יצמיד אותו כחלון צף שעוקב אחריכם לכל מרחב עבודה שתעברו אליו. נהדר בשביל נגני וידאו וכדומה.

 ![navigation-popped-window](images/navigation-popped-window.webp)

### מרחב עבודה scratchpad

יש מרחב עבודה scratchpad מיוחד בגודל מלא שמכסה את מרחב העבודה שאתם נמצאים עליו כרגע. ניגשים למה שעליו באמצעות `Super + S`, וממקמים שם חלונות באמצעות `Super + Alt + S`.

זה עובד היטב בשביל פקדים או מסוף שתרצו לקיים איתם אינטראקציה במהירות בלי לעזוב את מרחב העבודה הנוכחי.

### קונסולת Quake

לבסוף, יש קונסולת Quake בחצי גובה שיורדת מעל מרחב העבודה שאתם נמצאים עליו כרגע. החליפו את מצבה עם `Super + Grave`, ומקמו שם חלון באמצעות `Super + Shift + Grave`.

היא נפתחת עם סוכן ברירת המחדל שלכם מוכן לפעולה. בזמן שהקונסולה מחזיקה חלון אחד, היא יורדת כחלונית ממורכזת במקום להתפרס על פני המסך. שימו עליה יישום שני והיא חוזרת לרוחב המלא, כך שלשניים יש מקום לשבת זה לצד זה.

כדי להעביר חלון החוצה מה-scratchpad או מהקונסולה, שלחו אותו ישירות למרחב עבודה אחר עם משהו כמו `Super + Shift + 1`.

### לוקח קצת זמן להתרגל לזה!

לוקח קצת זמן להתרגל לנווט בשולחן העבודה שלכם כך, אבל ברגע שתתרגלו, יהיה קשה לחזור לחוויית שולחן עבודה מסורתית מונחית עכבר!
