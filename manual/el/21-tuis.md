# TUIs

## Lazygit

Το [Lazygit](https://github.com/jesseduffield/lazygit) είναι μια απολαυστική εναλλακτική σε κάτι σαν την εφαρμογή GitHub Desktop, και τρέχει μέσα στο τερματικό.

Μπορείτε να το εκτελέσετε απευθείας, πηγαίνοντας σε οποιονδήποτε κατάλογο που διαχειρίζεται το git και εκτελώντας `lazygit`. Ή μπορείτε να το εκτελέσετε μέσα στο Neovim, όπου μπορεί να ξεκινήσει με `Space G G`.

Μετακινείστε ανάμεσα στα διαφορετικά πλαίσια χρησιμοποιώντας `Tab`. Στο πλαίσιο Files, επιλέγετε αρχεία για staging χρησιμοποιώντας `Space`, και στη συνέχεια μπορείτε να δημιουργήσετε ένα νέο commit χρησιμοποιώντας `c`. Μπορείτε να δείτε όλες τις διαθέσιμες εντολές χρησιμοποιώντας `?`.

## Btop

Το [Btop](https://github.com/aristocratos/btop) είναι ένας όμορφος διαχειριστής πόρων που δείχνει τη χρήση μνήμης, CPU, δίσκου και δικτύου. Παραθέτει επίσης όλες τις ενεργές διεργασίες και σας επιτρέπει να τις διαχειρίζεστε.

Το Omarchy το αποκαλεί Activity Monitor, και το ξεκινάτε από τον εκκινητή εφαρμογών ή πατώντας `Super + Shift + T`. Ανοίγει ως αιωρούμενο παράθυρο, το οποίο μπορείτε να τοποθετήσετε σε διάταξη πλακιδίων με `Super + T`.

## Herdr

Το [Herdr](https://github.com/omacom-io/herdr) είναι ένας διαχειριστής χώρου εργασίας τερματικού που σας δίνει χώρους εργασίας, καρτέλες και πλαίσια, και τα διατηρεί όλα σε λειτουργία σε μια μόνιμη συνεδρία από την οποία μπορείτε να αποσυνδεθείτε και στην οποία μπορείτε να επιστρέψετε αργότερα.

Το ξεκινάτε (ή επανασυνδέεστε στην υπάρχουσα συνεδρία σας) από τον εκκινητή εφαρμογών ή με `Super + Ctrl + Return`. Το Omarchy περιλαμβάνει μια διαμόρφωση Herdr που αντικατοπτρίζει τη διαμόρφωσή του για το Tmux, οπότε το πλήκτρο prefix είναι και εδώ `Ctrl + Space`. Μπορείτε να περιηγηθείτε σε όλες τις συντομεύσεις πληκτρολογίου με `Super + Ctrl + K`.

## Fastfetch

Το [Fastfetch](https://github.com/fastfetch-cli/fastfetch) δείχνει πληροφορίες συστήματος, όπως έκδοση πυρήνα, χρόνο λειτουργίας, θέμα, CPU, μνήμη και άλλα. Είναι ο διάδοχος του δημοφιλούς εργαλείου neofetch.

Το Omarchy το έχει εντάξει ως _Σχετικά_ στο μενού Omarchy (`Super + Space`).

## Cliamp

Το [Cliamp](https://www.cliamp.stream/) είναι ένα ρετρό πρόγραμμα αναπαραγωγής μουσικής για τερματικό εμπνευσμένο από το Winamp 2.x, πλήρες με ενσωματωμένους ραδιοφωνικούς σταθμούς για lo-fi beats. Εκκινήστε το με `Super + Shift + Alt + M`, ή από το μενού Omarchy στην ενότητα _Εφαρμογές_. Πατήστε `?` για την πλήρη λίστα συντομεύσεων πληκτρολογίου.

## Τι γίνεται με το Wi-Fi και το Bluetooth;

Δεν θα βρείτε TUIs για Wi-Fi και Bluetooth — αυτές οι δουλειές ανήκουν στο κέλυφος του Omarchy. Κάντε κλικ στο εικονίδιο Wi-Fi στην επάνω γραμμή (ή πατήστε `Super + Ctrl + N`) για να δείτε δίκτυα και να συνδεθείτε, και κάντε κλικ στο εικονίδιο Bluetooth (ή πατήστε `Super + Ctrl + B`) για να αντιστοιχίσετε και να συνδέσετε συσκευές. Δείτε τη [δικτύωση](35-networking.md) για ολόκληρη την ιστορία.

## Προσθήκη των δικών σας

Οποιοδήποτε πρόγραμμα τερματικού μπορεί να λάβει την πλήρη μεταχείριση εφαρμογής. Μεταβείτε στο _Εγκατάσταση > TUI_ στο μενού Omarchy (`Super + Space`), δώστε του ένα όνομα, μια εντολή εκκίνησης, ένα στυλ παραθύρου και ένα εικονίδιο, και θα εμφανιστεί στον εκκινητή εφαρμογών όπως κάθε άλλη εφαρμογή. Μπορείτε να το αφαιρέσετε ξανά από το _Κατάργηση > TUI_.
