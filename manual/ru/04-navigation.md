# Navigation

Всё в Omarchy делается с клавиатуры — _ВСЁ!_ Когда система только запускается, одной мышью буквально ничего не сделаешь. Но можно нажать `Super + Space`, чтобы открыть Omarchy Menu, а оттуда можно сделать практически всё.

Но меню Omarchy чаще всего даже не предполагается основным способом управления системой. Можно быстрее! Все самые важные приложения привязаны напрямую к отдельным горячим клавишам. Терминал запускается по `Super + Return`, а браузер — по `Super + Shift + Return`. Попробуйте сделать одно за другим, и вы увидите магию тайлинга Hyprland в действии:

 ![navigation-browser-terminal](images/navigation-browser-terminal.webp)

Затем можно нажать `Super + J`, чтобы сложить их друг над другом, а не рядом:

 ![navigation-stacked](images/navigation-stacked.webp)

Нажмите `Super + J` ещё раз, чтобы вернуть их в положение рядом. Затем попробуйте `Super + Shift + Arrow Right`, находясь в браузере, чтобы поменять окна местами.

Теперь попробуйте `Super + Shift + T`, чтобы запустить Activity monitor. Он появится как плавающее окно. Его можно сделать тайловым с помощью `Super + T` (и нажать это ещё раз, чтобы снова сделать его плавающим). Теперь нажмите `Super + Shift + F`, чтобы открыть файловый менеджер. Получится аккуратная схема из четырёх частей:

 ![navigation-fourway-tiling](images/navigation-fourway-tiling.webp)

Между окнами, чтобы сделать нужное активным, вы перемещаетесь с помощью `Super + Arrow`. Это переключит фокус и переместит курсор в центр нового приложения. У края экрана переход продолжится на монитор с той стороны.

Если нажать `Super + Shift + 2`, текущее сфокусированное приложение переместится на второе рабочее пространство. `Super + Shift + 1` перемещает его обратно. (А `Super + Shift + Alt + 2` переместит текущее сфокусированное приложение на второе рабочее пространство, не переключаясь на него).

При нескольких мониторах у каждого монитора есть свои рабочие пространства с 1 по 10. `Super + 2` переходит на второе рабочее пространство того монитора, на котором вы находитесь, а верхняя панель каждого монитора показывает его собственные рабочие пространства и то, которое он отображает. `Super + Tab` циклически переключает рабочие пространства на мониторе, на котором вы находитесь. `Super + Shift + Ctrl + Arrows` перемещает окно, на котором вы находитесь, на монитор в том направлении, на рабочее пространство, которое тот показывает, а `Super + Shift + Alt + Arrows` перемещает рабочее пространство, на котором вы находитесь, на монитор в том направлении, где оно получает тот же номер, если он свободен. Монитор сохраняет свои рабочие пространства, когда вы его отключаете: они присоединяются к другому экрану, нумеруясь после тех, что у него уже есть, и возвращаются под своими старыми номерами, когда монитор возвращается.

Если удерживать `Super` и щёлкнуть мышью по окну, можно будет переставить его. Если удерживать `Super` и использовать правую кнопку мыши, можно свободно менять размер окна.

Окно закрывается по `Super + W` или `Super + Q` (а все окна — по `Ctrl + Alt + Delete`).

Также можно перейти в полноэкранный режим по `Super + F` или даже просто на всю ширину (с сохранением верхней панели) по `Super + Alt + F`, или в полноэкранный режим внутри окна по `Super + Ctrl + F` (отлично для YouTube!).

### Dwindle vs scrolling layout

Раскладка Omarchy по умолчанию называется dwindle. Она сохраняет все окна, открытые на одном рабочем пространстве, видимыми в любой момент, даже если для этого их приходится уменьшать.

 ![navigation-dwindle-layout](images/navigation-dwindle-layout.webp)

Но также можно превратить рабочее пространство в scrolling layout, где окна выстраиваются рядом, за видимым краем дисплея. Отдельное рабочее пространство превращается в эту раскладку с помощью `Super + L`.

Повторное нажатие `Super + L` делает рабочее пространство плавающим, где окна свободно перекрываются и вы размещаете их сами, а третье нажатие возвращает его в dwindle. `Super + Alt + L` проходит по ним в обратном порядке. Окно, которое и так плавает — то, что вы вынесли с помощью `Super + T`, или приложение, которое всегда открывается плавающим, — остаётся плавающим, когда рабочее пространство возвращается к тайлингу. Верхняя панель помечает рабочее пространство, на котором вы находитесь, его раскладкой: квадрат для dwindle, круг для scrolling и треугольник для floating. Щелчок по этой метке также переключает раскладку по циклу.

 ![navigation-scrolling-layout](images/navigation-scrolling-layout.webp)

Выбор делается для каждого рабочего пространства и сохраняется. Так что можно держать рабочее пространство 1 на dwindle для просмотра веб-страниц, а рабочее пространство 2 на scrolling для кода, и они вернутся в таком виде после перезапуска.

Если хотите использовать scrolling layout по умолчанию, это можно задать в `~/.config/hypr/looknfeel.lua`:

```lua
hl.config({
  general = {
    layout = "scrolling",
  },
})
```

### Floating workspaces

Плавающее рабочее пространство работает как традиционный рабочий стол: окна перекрываются, а вы сами перемещаете их и меняете их размер. Каждое окно получает заголовок в цветах вашей темы, с кнопками свернуть, развернуть и закрыть. `Super + M` также сворачивает сфокусированное окно. Свёрнутое окно ждёт в dock; щёлкните по его приложению, чтобы вернуть его. Щёлкните по окну, чтобы вынести его вперёд. Меняйте его размер с любого края или угла. Дважды щёлкните по заголовку, чтобы развернуть окно, сохранив верхнюю панель в поле зрения, и ещё раз, чтобы вернуть его старый размер. Chrome и другие браузеры на основе Chromium, Disks и Document Viewer пропускают заголовок и вместо него используют собственный заголовок; `Super + Alt + F` разворачивает их, а `Super + M` сворачивает их.

Плавающее рабочее пространство также показывает dock с вашими закреплёнными приложениями, всем, что запущено, и сеткой всех приложений за кнопкой приложений, которую также открывают `Super + Alt + Space` и _Apps_ в меню Omarchy. Щёлкните правой кнопкой по приложению в сетке или нажмите `Delete`, чтобы удалить его. Щёлкните по приложению, чтобы открыть его или вынести его окно вперёд; щёлкните ещё раз, чтобы переключаться по циклу между его окнами. Files только возвращает окно с рабочего пространства, на котором вы находитесь, а в остальных случаях открывает новое, а Terminal и Agent всегда запускают ещё одно, хотя свёрнутое окно возвращается первым. Щелчок средней кнопкой открывает новое окно. Перетащите значок вдоль dock, чтобы переместить его; перетаскивание запущенного приложения в ряд с остальными оставляет его там. Щёлкните правой кнопкой, чтобы оставить приложение в dock, убрать его оттуда или завершить его работу. Dock уступает место полноэкранному окну. Щёлкните правой кнопкой по кнопке приложений, чтобы переместить dock к другому краю или сделать так, чтобы он скрывался, пока указатель не достигнет его края. Положение также находится в _Appearance > Dock > Dock Position_, а `omarchy dock position left` и `omarchy dock autohide on` задают оба параметра из терминала. Приложения, которые вы держите в dock, выглядят faded, пока они не запущены.

Новые рабочие пространства и все, которым вы не задали собственную раскладку с помощью `Super + L`, используют раскладку по умолчанию. Изменение значения по умолчанию сбрасывает на него каждое рабочее пространство без окон, а рабочее пространство с окнами сохраняет ту раскладку, которая у него есть. Окно, свёрнутое в dock, по-прежнему считается окном на рабочем пространстве, которое оно покинуло. Выберите это в _Appearance > Workspace Layout_: Tiling, Scrolling или Floating. `omarchy-hyprland-workspace-layout-default scrolling` задаёт это из терминала.

### Grouping windows

Окна можно группировать с помощью `Super + G`. Как только вы окажетесь в группе, каждое окно, запущенное при активной группе, будет принадлежать группе. Перемещаться между этими сгруппированными окнами можно с помощью `Super + Ctrl + Arrow Left/Right` или `Super + Alt + 1/2/3/4`, чтобы перейти напрямую к сгруппированным окнам по порядку.

Окно можно вывести из группы с помощью `Super + Alt + G` или разобрать всю группу, снова нажав `Super + G`. Наконец, окна вне группы можно переместить в неё с помощью `Super + Alt + Arrows`.

### Popping windows

Окно можно вынести из закрепления за рабочим пространством с помощью `Super + O`. Это закрепит его как плавающее окно, которое следует за вами на любое рабочее пространство, куда вы перейдёте. Отлично для видеоплееров и тому подобного.

 ![navigation-popped-window](images/navigation-popped-window.webp)

### Scratchpad workspace

Есть специальное рабочее пространство-черновик на весь размер, которое накладывается поверх любого рабочего пространства, на котором вы сейчас находитесь. Доступ к тому, что на нём находится, вы получаете с помощью `Super + S`, а окна туда помещаете с помощью `Super + Alt + S`.

Оно хорошо подходит для элементов управления или терминала, с которыми нужно быстро взаимодействовать, не покидая текущего рабочего пространства.

### Quake console

Наконец, есть консоль Quake на полвысоты, которая опускается поверх любого рабочего пространства, на котором вы сейчас находитесь. Переключайте её с помощью `Super + Grave`, а окно туда помещайте с помощью `Super + Shift + Grave`.

Она открывается с вашим агентом по умолчанию, готовым к работе. Пока консоль содержит одно окно, она опускается как центрированная панель, а не на всю ширину экрана. Поместите на неё второе приложение, и она вернётся на всю ширину, чтобы у двух было место расположиться рядом.

Чтобы убрать окно с черновика или консоли, отправьте его напрямую на другое рабочее пространство с помощью чего-то вроде `Super + Shift + 1`.

### It takes some getting used to!

Требуется некоторое время, чтобы привыкнуть так перемещаться по рабочему столу, но как только привыкнете, вернуться к традиционному рабочему столу, управляемому мышью, будет трудно!
