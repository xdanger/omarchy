# TUIs

## Lazygit

[Lazygit](https://github.com/jesseduffield/lazygit) হলো GitHub Desktop অ্যাপ্লিকেশনের মতো কিছুর একটি আনন্দদায়ক বিকল্প, এবং এটি টার্মিনালের ভিতরে চলে।

আপনি এটি সরাসরি চালাতে পারেন, git দ্বারা পরিচালিত যেকোনো ডিরেক্টরিতে গিয়ে `lazygit` চালিয়ে। অথবা আপনি এটি Neovim-এর ভিতরে চালাতে পারেন যেখানে এটি `Space G G` দিয়ে শুরু করা যায়।

আপনি `Tab` ব্যবহার করে বিভিন্ন প্যানের মধ্যে লাফিয়ে যান। Files প্যানে, আপনি `Space` ব্যবহার করে স্টেজিংয়ের জন্য ফাইল নির্বাচন করেন, এবং তারপর আপনি `c` ব্যবহার করে একটি নতুন কমিট তৈরি করতে পারেন। আপনি `?` ব্যবহার করে উপলব্ধ সব কমান্ড দেখতে পারেন।

## Btop

[Btop](https://github.com/aristocratos/btop) হলো একটি সুন্দর রিসোর্স ম্যানেজার যা মেমরি, CPU, ডিস্ক এবং নেটওয়ার্ক ব্যবহার দেখায়। এটি সব সক্রিয় প্রসেসের তালিকাও দেয়, এবং আপনাকে সেগুলো পরিচালনা করতে দেয়।

Omarchy এটিকে Activity Monitor বলে, এবং আপনি এটি অ্যাপ লঞ্চার থেকে অথবা `Super + Shift + T` চেপে শুরু করেন। এটি একটি ভাসমান উইন্ডো হিসেবে খোলে, যেটিকে আপনি `Super + T` দিয়ে টাইল করতে পারেন।

## Herdr

[Herdr](https://github.com/omacom-io/herdr) হলো একটি টার্মিনাল ওয়ার্কস্পেস ম্যানেজার যা আপনাকে ওয়ার্কস্পেস, ট্যাব এবং প্যান দেয়, এবং সেগুলো সব একটি স্থায়ী সেশনে চালু রাখে যেখান থেকে আপনি বিচ্ছিন্ন হয়ে পরে আবার ফিরে আসতে পারেন।

আপনি এটি শুরু করেন (অথবা আপনার বিদ্যমান সেশনে পুনরায় সংযুক্ত হন) অ্যাপ লঞ্চার থেকে অথবা `Super + Ctrl + Return` দিয়ে। Omarchy একটি Herdr কনফিগারেশন সরবরাহ করে যা এর Tmux কনফিগকে প্রতিফলিত করে, তাই এখানেও প্রিফিক্স কী হলো `Ctrl + Space`। আপনি `Super + Ctrl + K` দিয়ে সব কীবাইন্ডিং ব্রাউজ করতে পারেন।

## Fastfetch

[Fastfetch](https://github.com/fastfetch-cli/fastfetch) সিস্টেমের তথ্য দেখায়, যেমন কার্নেল সংস্করণ, আপটাইম, থিম, CPU, মেমরি এবং আরও অনেক কিছু। এটি জনপ্রিয় neofetch টুলের উত্তরসূরি।

Omarchy এটিকে Omarchy মেনুতে (`Super + Space`) _About_ হিসেবে প্যাকেজ করেছে।

## Cliamp

[Cliamp](https://www.cliamp.stream/) হলো Winamp 2.x দ্বারা অনুপ্রাণিত একটি রেট্রো টার্মিনাল মিউজিক প্লেয়ার, lo-fi beats-এর জন্য অন্তর্নির্মিত রেডিও স্টেশনসহ সম্পূর্ণ। এটি `Super + Shift + Alt + M` দিয়ে, অথবা Omarchy মেনুতে _Apps_-এর অধীনে চালু করুন। সম্পূর্ণ কীবাইন্ডিং তালিকার জন্য `?` চাপুন।

## Wi-Fi এবং Bluetooth-এর কী হবে?

আপনি Wi-Fi এবং Bluetooth-এর জন্য TUI পাবেন না — সেই কাজগুলো Omarchy শেলের। নেটওয়ার্ক দেখতে এবং সংযোগ করতে উপরের বারে Wi-Fi আইকনে ক্লিক করুন (অথবা `Super + Ctrl + N` চাপুন), এবং ডিভাইস পেয়ার ও সংযোগ করতে Bluetooth আইকনে ক্লিক করুন (অথবা `Super + Ctrl + B` চাপুন)। সম্পূর্ণ বিবরণের জন্য [networking](35-networking.md) দেখুন।

## নিজেরটি যোগ করা

যেকোনো টার্মিনাল প্রোগ্রাম সম্পূর্ণ অ্যাপের মর্যাদা পেতে পারে। Omarchy মেনুতে (`Super + Space`) _Install > TUI_-তে যান, এটিকে একটি নাম, একটি লঞ্চ কমান্ড, একটি উইন্ডো স্টাইল এবং একটি আইকন দিন, এবং এটি অন্য যেকোনো অ্যাপ্লিকেশনের মতো অ্যাপ লঞ্চারে দেখা যাবে। আপনি _Remove > TUI_-এর অধীনে এটি আবার সরিয়ে ফেলতে পারেন।
