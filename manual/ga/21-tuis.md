# TUIs

## Lazygit

Is rogha thaitneamhach é [Lazygit](https://github.com/jesseduffield/lazygit) ar rud éigin cosúil leis an bhfeidhmchlár GitHub Desktop, agus ritheann sé taobh istigh den teirminéal.

Is féidir leat é a rith go díreach, trí dhul chuig aon eolaire atá á bhainistiú ag git agus `lazygit` a rith. Nó is féidir leat é a rith taobh istigh de Neovim, áit ar féidir é a thosú le `Space G G`.

Léimeann tú idir na pánaí éagsúla le `Tab`. Sa phána Files, roghnaíonn tú comhaid le cur ar stáitse le `Space`, agus ansin is féidir leat commit nua a chruthú le `c`. Is féidir leat na horduithe go léir atá ar fáil a fheiceáil le `?`.

## Btop

Is bainisteoir acmhainní álainn é [Btop](https://github.com/aristocratos/btop) a thaispeánann úsáid chuimhne, CPU, diosca agus líonra. Liostaíonn sé na próisis ghníomhacha go léir freisin, agus tugann sé cead duit iad a bhainistiú.

Tugann Omarchy Activity Monitor air, agus tosaíonn tú é ón tosaitheoir feidhmchlár nó trí `Super + Shift + T` a bhrú. Osclaíonn sé mar fhuinneog ar snámh, ar féidir leat í a thíleáil le `Super + T`.

## Herdr

Is bainisteoir spásanna oibre teirminéil é [Herdr](https://github.com/omacom-io/herdr) a thugann spásanna oibre, cluaisíní agus pánaí duit, agus a choinníonn iad go léir ag rith i seisiún buan ar féidir leat dícheangal uaidh agus filleadh air níos déanaí.

Tosaíonn tú é (nó athcheanglaíonn tú le do sheisiún reatha) ón tosaitheoir feidhmchlár nó le `Super + Ctrl + Return`. Soláthraíonn Omarchy cumraíocht Herdr a mheaitseálann a chumraíocht Tmux, mar sin is í `Ctrl + Space` an réimír eochrach anseo freisin. Is féidir leat na heochaircheangail go léir a bhrabhsáil le `Super + Ctrl + K`.

## Fastfetch

Taispeánann [Fastfetch](https://github.com/fastfetch-cli/fastfetch) faisnéis faoin gcóras, cosúil le leagan na heithne, aga ar líne, téama, CPU, cuimhne, agus tuilleadh. Is comharba é ar an uirlis mhóréilimh neofetch.

Tá sé seo pacáilte ag Omarchy mar _About_ i roghchlár Omarchy (`Super + Space`).

## Cliamp

Is seinnteoir ceoil teirminéil retro é [Cliamp](https://www.cliamp.stream/) a spreag Winamp 2.x, agus stáisiúin raidió ionsuite ann le haghaidh buillí lo-fi. Seol é le `Super + Shift + Alt + M`, nó ó roghchlár Omarchy faoi _Apps_. Brúigh `?` chun liosta iomlán na n-eochaircheangal a fheiceáil.

## Cad faoi Wi-Fi agus Bluetooth?

Ní bhfaighidh tú TUIs le haghaidh Wi-Fi agus Bluetooth — baineann na poist sin le blaosc Omarchy. Cliceáil an deilbhín Wi-Fi sa bharra uachtarach (nó brúigh `Super + Ctrl + N`) chun líonraí a fheiceáil agus ceangal leo, agus cliceáil an deilbhín Bluetooth (nó brúigh `Super + Ctrl + B`) chun gléasanna a phéireáil agus a cheangal. Féach [líonrú](35-networking.md) chun an scéal iomlán a fháil.

## Ceann de do chuid féin a chur leis

Is féidir le haon chlár teirminéil an chóireáil iomlán mar fheidhmchlár a fháil. Téigh chuig _Install > TUI_ i roghchlár Omarchy (`Super + Space`), tabhair ainm dó, ordú seolta, stíl fuinneoige, agus deilbhín, agus beidh sé le feiceáil sa tosaitheoir feidhmchlár díreach cosúil le haon fheidhmchlár eile. Is féidir leat é a bhaint arís faoi _Remove > TUI_.
