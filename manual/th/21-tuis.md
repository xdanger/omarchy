# TUIs

## Lazygit

[Lazygit](https://github.com/jesseduffield/lazygit) เป็นทางเลือกที่น่าใช้แทนอะไรอย่างแอปพลิเคชัน GitHub Desktop และมันทำงานอยู่ภายในเทอร์มินัล

คุณสามารถรันมันได้โดยตรง โดยเข้าไปยังไดเรกทอรีใด ๆ ที่จัดการด้วย git แล้วรัน `lazygit` หรือคุณจะรันมันภายใน Neovim ก็ได้ ซึ่งสามารถเริ่มได้ด้วย `Space G G`

คุณสลับไปมาระหว่างบานหน้าต่างต่าง ๆ ได้โดยใช้ `Tab` ในบานหน้าต่าง Files คุณเลือกไฟล์สำหรับ staging ได้โดยใช้ `Space` จากนั้นคุณสามารถสร้าง commit ใหม่ได้โดยใช้ `c` คุณสามารถดูคำสั่งทั้งหมดที่มีได้โดยใช้ `?`

## Btop

[Btop](https://github.com/aristocratos/btop) เป็นตัวจัดการทรัพยากรที่สวยงาม ซึ่งแสดงการใช้งานหน่วยความจำ, CPU, ดิสก์ และเครือข่าย นอกจากนี้ยังแสดงรายการโปรเซสที่กำลังทำงานทั้งหมด และให้คุณจัดการโปรเซสเหล่านั้นได้

Omarchy เรียกมันว่า Activity Monitor และคุณเปิดมันได้จากตัวเปิดแอปหรือโดยการกด `Super + Shift + T` มันจะเปิดเป็นหน้าต่างแบบลอย ซึ่งคุณสามารถจัดวางแบบเรียงต่อกันได้ด้วย `Super + T`

## Herdr

[Herdr](https://github.com/omacom-io/herdr) เป็นตัวจัดการพื้นที่ทำงานในเทอร์มินัลที่ให้คุณมี workspace, แท็บ และบานหน้าต่าง และทำให้ทั้งหมดยังคงทำงานอยู่ในเซสชันแบบถาวรที่คุณสามารถแยกออกมาและกลับเข้ามาในภายหลังได้

คุณเริ่มมัน (หรือกลับเข้าไปเชื่อมต่อกับเซสชันที่มีอยู่ของคุณอีกครั้ง) ได้จากตัวเปิดแอปหรือด้วย `Super + Ctrl + Return` Omarchy มาพร้อมกับการตั้งค่า Herdr ที่สะท้อนการตั้งค่า Tmux ของมัน ดังนั้นคีย์ prefix จึงเป็น `Ctrl + Space` ที่นี่เช่นกัน คุณสามารถเรียกดูการผูกคีย์ทั้งหมดได้ด้วย `Super + Ctrl + K`

## Fastfetch

[Fastfetch](https://github.com/fastfetch-cli/fastfetch) แสดงข้อมูลระบบ เช่น เวอร์ชัน kernel, เวลาทำงาน, ธีม, CPU, หน่วยความจำ และอื่น ๆ มันเป็นตัวต่อยอดจากเครื่องมือ neofetch ที่ได้รับความนิยม

Omarchy ได้แพ็กเกจอันนี้ไว้ในชื่อ _About_ ในเมนู Omarchy (`Super + Space`)

## Cliamp

[Cliamp](https://www.cliamp.stream/) เป็นเครื่องเล่นเพลงในเทอร์มินัลสไตล์เรโทรที่ได้รับแรงบันดาลใจจาก Winamp 2.x พร้อมด้วยสถานีวิทยุในตัวสำหรับบีท lo-fi เปิดมันได้ด้วย `Super + Shift + Alt + M` หรือจากเมนู Omarchy ภายใต้ _Apps_ กด `?` เพื่อดูรายการการผูกคีย์ทั้งหมด

## แล้ว Wi-Fi กับ Bluetooth ล่ะ?

คุณจะไม่เจอ TUI สำหรับ Wi-Fi และ Bluetooth — งานเหล่านั้นเป็นของ Omarchy shell คลิกไอคอน Wi-Fi ในแถบด้านบน (หรือกด `Super + Ctrl + N`) เพื่อดูเครือข่ายและเชื่อมต่อ และคลิกไอคอน Bluetooth (หรือกด `Super + Ctrl + B`) เพื่อจับคู่และเชื่อมต่ออุปกรณ์ ดูเรื่องราวทั้งหมดได้ที่ [เครือข่าย](35-networking.md)

## การเพิ่มของคุณเอง

โปรแกรมเทอร์มินัลใด ๆ ก็สามารถได้รับการดูแลแบบแอปเต็มรูปแบบได้ ไปที่ _Install > TUI_ ในเมนู Omarchy (`Super + Space`) ตั้งชื่อให้มัน ใส่คำสั่งเปิดใช้งาน สไตล์หน้าต่าง และไอคอน แล้วมันจะปรากฏในตัวเปิดแอปเหมือนกับแอปพลิเคชันอื่น ๆ คุณสามารถลบมันออกอีกครั้งได้ภายใต้ _Remove > TUI_
