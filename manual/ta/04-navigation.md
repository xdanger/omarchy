# வழிசெலுத்தல்

Omarchy-இல் எல்லாமே விசைப்பலகை வழியாகத்தான் நடக்கும் — _எல்லாமே!_ கணினி முதலில் தொடங்கும்போது, சுட்டியை மட்டும் வைத்துக்கொண்டு உங்களால் உண்மையிலேயே எதுவும் செய்ய முடியாது. ஆனால் நீங்கள் `Super + Space` ஐ அழுத்தி Omarchy மெனுவை வெளிப்படுத்தலாம், இங்கிருந்து கிட்டத்தட்ட எல்லாவற்றையும் செய்யலாம்.

ஆனால் பெரும்பாலான நேரங்களில் Omarchy மெனுதான் கணினியை இயக்கும் முக்கிய வழியாக இருக்க வேண்டும் என்பதுகூட நோக்கமல்ல. அதைவிட வேகமாகச் செயல்பட முடியும்! மிக முக்கியமான பயன்பாடுகள் அனைத்தும் தனித்தனி ஹாட்கீகளுடன் நேரடியாக இணைக்கப்பட்டுள்ளன. டெர்மினலை `Super + Return` உடனும் உலாவியை `Super + Shift + Return` உடனும் தொடங்குவீர்கள். ஒன்றன் பின் ஒன்றாக முயன்று பாருங்கள், Hyprland-இன் டைலிங்கின் மாயாஜாலம் செயலில் இருப்பதைப் பார்ப்பீர்கள்:

 ![navigation-browser-terminal](images/navigation-browser-terminal.webp)

பிறகு நீங்கள் `Super + J` ஐ அழுத்தி, அவற்றை அருகருகே வைப்பதற்குப் பதிலாக ஒன்றின் மேல் ஒன்றாக அடுக்கலாம்:

 ![navigation-stacked](images/navigation-stacked.webp)

`Super + J` ஐ மீண்டும் அழுத்தினால் அவை அருகருகே இருந்த நிலைக்குத் திரும்பும். பிறகு உலாவியில் இருக்கும்போது `Super + Shift + Arrow Right` ஐ முயன்று பார்த்து, சாளரங்களை இடமாற்றுங்கள்.

இப்போது `Super + Shift + T` ஐ முயன்று Activity மானிட்டரைத் தொடங்குங்கள். அது ஒரு மிதக்கும் சாளரமாகத் தோன்றும். `Super + T` ஐப் பயன்படுத்தி அதை டைல் செய்யலாம் (அதையே மீண்டும் அழுத்தினால் அது மீண்டும் மிதக்கும்). இப்போது `Super + Shift + F` ஐ அழுத்தி கோப்பு மேலாளரைத் திறங்கள். உங்களுக்கு நேர்த்தியான நான்கு பிரிவு அமைப்பு கிடைக்கும்:

 ![navigation-fourway-tiling](images/navigation-fourway-tiling.webp)

நீங்கள் செயலில் இருக்க விரும்பும் சாளரத்திற்கு `Super + Arrow` உடன் செல்வீர்கள். இது ஃபோகஸை மாற்றி, கர்சரைப் புதிய பயன்பாட்டின் மையத்திற்கு நகர்த்தும். ஒரு திரையின் விளிம்பில், அது அந்தப் பக்கத்தில் உள்ள மானிட்டருக்குத் தொடர்ந்து செல்லும்.

நீங்கள் `Super + Shift + 2` ஐ அழுத்தினால், தற்போது ஃபோகஸில் உள்ள பயன்பாட்டை இரண்டாவது பணியிடத்திற்கு நகர்த்துவீர்கள். `Super + Shift + 1` அதைத் திரும்ப நகர்த்தும். (மேலும் `Super + Shift + Alt + 2` தற்போது ஃபோகஸில் உள்ள பயன்பாட்டை, அதற்கு மாறாமலேயே, இரண்டாவது பணியிடத்திற்கு நகர்த்தும்).

ஒன்றுக்கு மேற்பட்ட மானிட்டர்கள் இருக்கும்போது, ஒவ்வொரு மானிட்டருக்கும் சொந்தமாக 1 முதல் 10 வரையிலான பணியிடங்கள் இருக்கும். `Super + 2` நீங்கள் இருக்கும் மானிட்டரின் இரண்டாவது பணியிடத்திற்குச் செல்லும், ஒவ்வொரு மானிட்டரின் மேல் பட்டையும் அதன் சொந்தப் பணியிடங்களையும் அது காட்டிக்கொண்டிருக்கும் பணியிடத்தையும் காட்டும். `Super + Tab` நீங்கள் இருக்கும் மானிட்டரில் உள்ள பணியிடங்களைச் சுழற்சியாக மாற்றும். `Super + Shift + Ctrl + Arrows` நீங்கள் இருக்கும் சாளரத்தை அந்தத் திசையில் உள்ள மானிட்டருக்கு, அது காட்டிக்கொண்டிருக்கும் பணியிடத்திற்கு நகர்த்தும், மேலும் `Super + Shift + Alt + Arrows` நீங்கள் இருக்கும் பணியிடத்தை அந்தத் திசையில் உள்ள மானிட்டருக்கு நகர்த்தும், அங்கு அது காலியாக இருந்தால் அதே எண்ணை எடுத்துக்கொள்ளும். நீங்கள் ஒரு மானிட்டரைத் துண்டிக்கும்போது அது அதன் பணியிடங்களைத் தக்கவைத்துக்கொள்ளும்: அவை வேறொரு திரையின் பணியிடங்களுடன், அதில் ஏற்கனவே உள்ளவற்றுக்குப் பிறகு எண்ணிடப்பட்டு இணையும், மானிட்டர் திரும்ப வரும்போது அவற்றின் பழைய எண்களுக்குத் திரும்பச் செல்லும்.

நீங்கள் `Super` ஐ அழுத்திப் பிடித்து, சுட்டியைப் பயன்படுத்தி ஒரு சாளரத்தைக் கிளிக் செய்தால், அது அமர்ந்திருக்கும் இடத்தை மறுசீரமைக்க முடியும். நீங்கள் `Super` ஐ அழுத்திப் பிடித்து, சுட்டியின் வலது பொத்தானைப் பயன்படுத்தினால், சாளரத்தைத் தடையின்றி மறுஅளவு செய்ய முடியும்.

ஒரு சாளரத்தை `Super + W` அல்லது `Super + Q` உடன் மூடுவீர்கள் (எல்லா சாளரங்களையும் `Ctrl + Alt + Delete` உடன் மூடுவீர்கள்).

நீங்கள் `Super + F` உடன் முழுத் திரைக்கும் செல்லலாம் அல்லது `Super + Alt + F` உடன் வெறும் முழு அகலத்திற்கும் (மேல் பட்டையைத் தக்கவைத்து) செல்லலாம் அல்லது `Super + Ctrl + F` உடன் ஒரு சாளரத்திற்குள் முழுத் திரையாகச் செல்லலாம் (YouTube-க்கு நல்லது!).

### Dwindle vs scrolling தளவமைப்பு

Omarchy-இன் இயல்புநிலை தளவமைப்பு dwindle என்று அழைக்கப்படுகிறது. நீங்கள் ஒரே பணியிடத்தில் திறக்கும் எல்லா சாளரங்களையும் அது எல்லா நேரங்களிலும் தெரியும்படி வைத்திருக்கும், அவற்றைச் சுருக்க வேண்டியிருந்தாலும் கூட.

 ![navigation-dwindle-layout](images/navigation-dwindle-layout.webp)

ஆனால் ஒரு பணியிடத்தை, சாளரங்கள் அருகருகே, திரையின் தெரியும் விளிம்புக்கு அப்பால் வரிசைப்படுத்தப்படும் scrolling தளவமைப்பாக மாற்றவும் நீங்கள் தேர்வு செய்யலாம். `Super + L` வழியாக ஒற்றைப் பணியிடத்தை இந்தத் தளவமைப்பாக மாற்றுவீர்கள்.

`Super + L` ஐ மீண்டும் அழுத்தினால் பணியிடம் மிதக்கும் நிலைக்கு மாறும், அங்கு சாளரங்கள் தடையின்றி ஒன்றன் மேல் ஒன்று படிந்திருக்கும், அவற்றை நீங்களே வைப்பீர்கள், மூன்றாவது முறை அழுத்தினால் அது dwindle-க்குத் திரும்பும். `Super + Alt + L` அவற்றை வழியாக மற்ற திசையில் செல்லும். எப்படியும் மிதக்கும் ஒரு சாளரம் — நீங்கள் `Super + T` உடன் வெளியே எடுத்த ஒன்று, அல்லது எப்போதும் மிதந்தபடி திறக்கும் ஒரு பயன்பாடு — பணியிடம் டைலிங்கிற்குத் திரும்பும்போதும் தொடர்ந்து மிதக்கும். மேல் பட்டை நீங்கள் இருக்கும் பணியிடத்தை அதன் தளவமைப்புடன் குறிக்கும்: dwindle-க்கு ஒரு சதுரம், scrolling-க்கு ஒரு வட்டம், மிதத்தலுக்கு ஒரு முக்கோணம். அந்தக் குறியைக் கிளிக் செய்தாலும் தளவமைப்பு சுழற்சியாக மாறும்.

 ![navigation-scrolling-layout](images/navigation-scrolling-layout.webp)

இந்தத் தேர்வு ஒவ்வொரு பணியிடத்திற்கும் தனித்தனியானது, அது நிலைத்திருக்கும். எனவே நீங்கள் பணியிடம் 1-ஐ உலாவலுக்கு dwindle-இலும் பணியிடம் 2-ஐ குறியீட்டிற்கு scrolling-இலும் வைத்திருக்கலாம், மறுதொடக்கத்திற்குப் பிறகும் அவை அப்படியே திரும்ப வரும்.

நீங்கள் scrolling தளவமைப்பை இயல்புநிலையாகப் பயன்படுத்த விரும்பினால், அதை `~/.config/hypr/looknfeel.lua` இல் அமைக்கலாம்:

```lua
hl.config({
  general = {
    layout = "scrolling",
  },
})
```

### மிதக்கும் பணியிடங்கள்

ஒரு மிதக்கும் பணியிடம் ஒரு பாரம்பரிய டெஸ்க்டாப்பைப் போல வேலை செய்யும்: சாளரங்கள் ஒன்றன் மேல் ஒன்று படிந்திருக்கும், அவற்றை நீங்களே நகர்த்தி அளவிடுவீர்கள். ஒவ்வொரு சாளரத்திற்கும் உங்கள் தீமின் வண்ணங்களில் ஒரு தலைப்புப் பட்டை கிடைக்கும், அதில் சிறிதாக்க, பெரிதாக்க, மூடுவதற்கான பொத்தான்கள் இருக்கும். `Super + M` ஃபோகஸில் உள்ள சாளரத்தையும் சிறிதாக்கும். சிறிதாக்கப்பட்ட சாளரம் டாக்கில் காத்திருக்கும்; அதைத் திரும்பக் கொண்டுவர அதன் பயன்பாட்டைக் கிளிக் செய்யுங்கள். ஒரு சாளரத்தை முன்னால் கொண்டுவர அதைக் கிளிக் செய்யுங்கள். எந்த விளிம்பிலிருந்தும் அல்லது மூலையிலிருந்தும் அதை மறுஅளவு செய்யுங்கள். மேல் பட்டையைப் பார்வையில் வைத்தபடி சாளரத்தைப் பெரிதாக்க ஒரு தலைப்புப் பட்டையை இருமுறை கிளிக் செய்யுங்கள், அதன் பழைய அளவைத் திரும்பப் பெற மீண்டும் செய்யுங்கள். Chrome மற்றும் பிற Chromium அடிப்படையிலான உலாவிகள், Disks மற்றும் Document Viewer தலைப்புப் பட்டையைத் தவிர்த்துவிட்டு அதற்குப் பதிலாக அவற்றின் சொந்தத் தலைப்பைப் பயன்படுத்தும்; `Super + Alt + F` அவற்றைப் பெரிதாக்கும், `Super + M` அவற்றைச் சிறிதாக்கும்.

ஒரு மிதக்கும் பணியிடம் ஒரு டாக்கையும் காட்டும், அதில் உங்கள் பின் செய்யப்பட்ட பயன்பாடுகள், இயங்கிக்கொண்டிருக்கும் எல்லாமும், பயன்பாடுகள் பொத்தானுக்குப் பின்னால் உள்ள ஒவ்வொரு பயன்பாட்டின் கட்டமும் இருக்கும், அதை `Super + Alt + Space` மற்றும் Omarchy மெனுவில் உள்ள _Apps_ ஆகியவையும் திறக்கும். கட்டத்தில் உள்ள ஒரு பயன்பாட்டை வலது கிளிக் செய்யுங்கள், அல்லது `Delete` ஐ அழுத்துங்கள், அதை நிறுவல் நீக்க. ஒரு பயன்பாட்டைத் திறக்க, அல்லது அதன் சாளரத்தை முன்னால் கொண்டுவர அதைக் கிளிக் செய்யுங்கள்; அதன் சாளரங்களைச் சுழற்சியாக மாற்ற மீண்டும் கிளிக் செய்யுங்கள். Files நீங்கள் இருக்கும் பணியிடத்திலிருந்து ஒரு சாளரத்தை மட்டுமே திரும்பக் கொண்டுவரும், இல்லையெனில் ஒரு புதியதைத் திறக்கும், மேலும் Terminal மற்றும் Agent எப்போதும் இன்னொன்றைத் தொடங்கும், ஆனாலும் சிறிதாக்கப்பட்ட சாளரம் முதலில் திரும்ப வரும். நடு கிளிக் ஒரு புதிய சாளரத்தைத் திறக்கும். ஒரு ஐகானை டாக்கில் இழுத்து அதை நகர்த்துங்கள்; இயங்கிக்கொண்டிருக்கும் ஒரு பயன்பாட்டை மற்றவற்றுக்கு இடையில் இழுத்தால் அது அங்கேயே இருக்கும். ஒரு பயன்பாட்டை டாக்கில் வைத்திருக்க, அதை வெளியே எடுக்க, அல்லது அதை விட்டு வெளியேற வலது கிளிக் செய்யுங்கள். டாக் ஒரு முழுத்திரை சாளரத்திற்கு வழிவிட்டு விலகும். டாக்கை வேறொரு விளிம்பிற்கு நகர்த்த அல்லது சுட்டி அதன் விளிம்பை அடையும் வரை அது மறைந்திருக்கும்படி செய்ய பயன்பாடுகள் பொத்தானை வலது கிளிக் செய்யுங்கள். அந்த நிலை _Appearance > Dock > Dock Position_ இன் கீழும் உள்ளது, மேலும் `omarchy dock position left` மற்றும் `omarchy dock autohide on` இரண்டையும் ஒரு டெர்மினலிலிருந்து அமைக்கும். நீங்கள் டாக்கில் வைத்திருக்கும் பயன்பாடுகள் அவை இயங்காதபோது மங்கலாக இருக்கும்.

புதிய பணியிடங்களும், `Super + L` உடன் சொந்தமாக ஒரு தளவமைப்பை நீங்கள் கொடுக்காத எவையும், இயல்புநிலை தளவமைப்பைப் பயன்படுத்தும். இயல்புநிலையை மாற்றினால் சாளரங்கள் இல்லாத ஒவ்வொரு பணியிடமும் அதற்கு மீட்டமைக்கப்படும், அதேவேளை அதில் சாளரங்கள் உள்ள ஒன்று அதில் உள்ள தளவமைப்பைத் தக்கவைத்துக்கொள்ளும். டாக்கிற்குச் சிறிதாக்கப்பட்ட ஒரு சாளரம் அது விட்டுச் சென்ற பணியிடத்தில் உள்ள ஒரு சாளரமாகவே இன்னும் கணக்கிடப்படும். அதை _Appearance > Workspace Layout_ இன் கீழ் தேர்ந்தெடுங்கள்: Tiling, Scrolling, அல்லது Floating. `omarchy-hyprland-workspace-layout-default scrolling` அதை ஒரு டெர்மினலிலிருந்து அமைக்கும்.

### சாளரங்களைக் குழுவாக்குதல்

சாளரங்களை `Super + G` ஐப் பயன்படுத்திக் குழுவாக்க முடியும். நீங்கள் ஒரு குழுவில் இருந்தவுடன், அது செயலில் இருக்கும்போது நீங்கள் தொடங்கும் ஒவ்வொரு சாளரமும் அந்தக் குழுவைச் சேர்ந்ததாக இருக்கும். இந்தக் குழுவாக்கப்பட்ட சாளரங்களுக்கு இடையில் `Super + Ctrl + Arrow Left/Right` ஐப் பயன்படுத்தி நகரலாம் அல்லது `Super + Alt + 1/2/3/4` ஐப் பயன்படுத்திக் குழுவாக்கப்பட்ட சாளரங்களுக்கு வரிசைப்படி நேரடியாகச் செல்லலாம்.

நீங்கள் ஒரு சாளரத்தை `Super + Alt + G` உடன் குழுவிலிருந்து வெளியே நகர்த்தலாம் அல்லது `Super + G` ஐ மீண்டும் அழுத்தி முழுக் குழுவையும் கலைக்கலாம். இறுதியாக, குழுவிற்கு வெளியே உள்ள சாளரங்களை `Super + Alt + Arrows` உடன் அதற்குள் நகர்த்தலாம்.

### சாளரங்களை வெளியே எடுத்தல்

ஒரு சாளரத்தை அதன் பணியிட ஒதுக்கீட்டிலிருந்து `Super + O` உடன் வெளியே எடுக்கலாம். அது அதை நீங்கள் எந்தப் பணியிடத்திற்குச் சென்றாலும் உங்களைப் பின்தொடரும் ஒரு மிதக்கும் சாளரமாகப் பின் செய்யும். வீடியோ பிளேயர்கள் போன்றவற்றுக்கு மிகச் சிறந்தது.

### Scratchpad பணியிடம்

நீங்கள் தற்போது இருக்கும் எந்தப் பணியிடத்தின் மீதும் மேலடுக்காக வரும் ஒரு சிறப்பு முழு அளவு scratchpad பணியிடம் உள்ளது. அதில் உள்ளவற்றை `Super + S` ஐப் பயன்படுத்தி அணுகுவீர்கள், அங்கு சாளரங்களை `Super + Alt + S` ஐப் பயன்படுத்தி வைப்பீர்கள்.

தற்போதைய பணியிடத்தை விட்டு வெளியேறாமல் விரைவாகத் தொடர்புகொள்ள விரும்பும் கட்டுப்பாடுகளுக்கு அல்லது ஒரு டெர்மினலுக்கு இது நன்றாக வேலை செய்யும்.

### Quake கன்சோல்

இறுதியாக, நீங்கள் தற்போது இருக்கும் எந்தப் பணியிடத்தின் மீதும் கீழே விழும் ஒரு அரை உயர Quake கன்சோல் உள்ளது. அதை `Super + Grave` உடன் மாற்றுங்கள், அங்கு ஒரு சாளரத்தை `Super + Shift + Grave` ஐப் பயன்படுத்தி வையுங்கள்.

அது உங்கள் இயல்புநிலை agent தயாராக இருக்கத் திறக்கும். கன்சோல் ஒற்றைச் சாளரத்தை வைத்திருக்கும்போது, அது திரையை நிறைப்பதற்குப் பதிலாக ஒரு மையப்படுத்தப்பட்ட பேனலாகக் கீழே விழும். அதில் இரண்டாவது பயன்பாட்டை வைத்தால் அது முழு அகலத்திற்குத் திரும்பச் செல்லும், எனவே அந்த இரண்டும் அருகருகே அமர இடம் கிடைக்கும்.

ஒரு சாளரத்தை scratchpad-இலிருந்தோ கன்சோலிலிருந்தோ நகர்த்த, அதை `Super + Shift + 1` போன்ற ஒன்றுடன் நேரடியாக வேறொரு பணியிடத்திற்கு அனுப்புங்கள்.

### பழகக் கொஞ்சம் நேரம் ஆகும்!

இப்படி உங்கள் டெஸ்க்டாப்பில் செல்வதற்குப் பழகக் கொஞ்சம் நேரம் ஆகும், ஆனால் நீங்கள் பழகிவிட்டால், ஒரு பாரம்பரிய சுட்டியால் இயக்கப்படும் டெஸ்க்டாப் அனுபவத்திற்குத் திரும்பச் செல்வது கடினமாக இருக்கும்!
